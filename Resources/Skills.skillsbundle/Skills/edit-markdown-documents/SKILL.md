---
name: edit-markdown-documents
description: Read, add to or rewrite a person's Markdown documents in Ouro MD, such as notes, plans and drafts, when they ask about a document or want text added to one.
---

When the person says "this document", "my notes" or "the plan" without a name, use the document on screen; the tools do that when no document is given. Otherwise find the document by name or folder first.

To answer a question about a document, read it with the get Markdown tool and answer from its text. Quote short passages rather than retelling the whole document.

To add something (a to-do, a note, a paragraph), use the add tool. It puts the text at the end as a new paragraph and the person can undo it in one step. Write the addition as Markdown: a to-do is `- [ ] item`, a heading starts with `#`.

Use the replace tool only when the person asks to rewrite, restructure or clear a whole document. It replaces every line and asks the person to confirm first. To change one part, read the document, make the change in the full text, then replace it, and say what changed.

After an edit, say in one sentence what changed and in which document.
