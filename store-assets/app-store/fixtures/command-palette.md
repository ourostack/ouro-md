# Command palette flow

Use Shift-Command-P to jump to common workspace actions while the Markdown file
stays focused.

## Common commands

| Command | Result |
| --- | --- |
| Open Folder | Choose a local workspace. |
| Search Folder | Search files on disk. |
| Show Outline | Jump through headings. |
| Export PDF | Produce a reviewable document. |
| Export HTML | Save a portable web page. |
| Switch Theme | Change the reading palette. |

> The App Store build disables direct-download updates and telemetry by default.

## Shortcut notes

- Command-O opens a file.
- Shift-Command-O opens a folder.
- Shift-Command-P opens the command palette.
