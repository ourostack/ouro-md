# Workspace notes

Ouro MD opens Markdown files from a normal Mac folder. This fixture is synthetic
store-review content, not a user document.

## Open local folders

- Keep drafts in Finder.
- Browse nearby files in the file tree.
- Search the folder without uploading the workspace.
- Export finished notes as PDF or self-contained HTML.

## Review checklist

| Surface | What to verify |
| --- | --- |
| File tree | Local folder navigation is visible. |
| Outline | Headings map to the current document. |
| Search | Results stay tied to files on disk. |
| Export | PDF and HTML are available from the app. |
