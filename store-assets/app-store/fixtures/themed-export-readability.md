# Themed readability

Ouro MD ships with light, dark, and reading-focused themes for Markdown files
that stay on the Mac.

## Export formats

| Format | Use |
| --- | --- |
| PDF | Share a fixed review copy. |
| HTML | Send a self-contained page. |
| Markdown | Keep source control friendly text. |

## Dark review

Graphite keeps headings, tables, code, and paragraphs readable without changing
the underlying file.

```json
{
  "accountRequired": false,
  "source": "local markdown"
}
```
