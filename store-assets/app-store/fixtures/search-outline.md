# Search and outline

Long Markdown files are easier to review when the folder search and document
outline are visible beside the editor.

## Workspace notes

Local files stay portable. Search results point back to the file and line that
matched, while the outline keeps the current document easy to scan.

## Search from the sidebar

Search for `local`, `export`, or a project term across Markdown files in the
open folder.

## Export and handoff

When the draft is ready, export PDF or HTML and keep the Markdown source in the
same folder.

## Review checklist

- The search sidebar has multiple results.
- The outline shows the current document sections.
- The rendered document remains readable beside both panels.
